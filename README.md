# Lista de Tarefas

Projeto simples de lista de tarefas desenvolvido para praticar HTML, CSS e JavaScript.

A aplicação permite adicionar tarefas, marcá-las como concluídas e removê-las diretamente pela interface, tudo rodando no navegador.

## Objetivo

Praticar:
- Estruturação de páginas com HTML
- Estilização básica com CSS
- Manipulação do DOM com JavaScript
- Uso de eventos de clique e duplo clique
- Organização de um projeto web simples

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas ao clicar
- Remover tarefas com duplo clique
- Limpar todas as tarefas com confirmação
- Interface simples e intuitiva

## Estrutura do projeto

index.html

README.md


## Como usar

1. Clone o repositório:
git clone https://github.com/ThiagoVenttura/Lista-de-Tarefas.git


2. Abra o arquivo `index.html` no navegador.

3. Digite uma tarefa no campo de texto e clique em **Adicionar tarefa**.

- Clique em uma tarefa para marcá-la como concluída  
- Dê dois cliques para removê-la  
- Use o botão **Limpar tudo** para apagar a lista inteira  

## Aprendizados

- Criação e manipulação dinâmica de elementos HTML
- Uso de eventos (`click` e `dblclick`)
- Validação simples de entrada de dados
- Interação do usuário com JavaScript
- Organização básica de arquivos em um projeto front-end
